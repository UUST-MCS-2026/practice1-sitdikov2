#Заметки по Git
Эксперимент А. Пустая папка
Папка не появилась в репозитории. Git не отслеживает пустые папки, потому что он хранит информацию только о файлах, а папки для него - это просто часть пути к файлу.
Чтобы папка оказалась в репозитории, мне пришлось создать внутри неё файл empty.txt. После этого Git увидел новый путь и добавил его в индекс.
