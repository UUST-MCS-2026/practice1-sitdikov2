Эксперимент Б. Исчезнувший файл



1\)Файл исчез из текущей версии проекта, но он остался в истории коммитов.



2\)Команда, показывающая содержимое: git show 0f1e736:about/decret.txt. Она вывела текст "секрет".



3\)Это значит, что если случайно закоммитить пароль, а потом удалить файл, пароль всё равно останется в истории Git навсегда. Любой, кто склонирует репозиторий, сможет найти его через историю. Поэтому нужно сразу менять скомпрометированные пароли.
